## About the Project

Galaxy Hospitals Ltd is a 65+ year old multi-specialty hospital based in Warananagar, Panhala, Maharashtra. This is their official website, built from scratch to give them a professional online presence.

The client needed a fast, clean, and SEO-optimized website that patients and the general public could use to find information about the hospital, its services, doctors, and contact details.

---

## Project Delivery

This was a complete end-to-end freelance engagement following a structured development process:

| Phase | What was done |
|-------|--------------|
| 1. Requirements | Gathered client requirements and prepared a Software Requirements Specification (SRS) document before development began |
| 2. Design & Development | Designed and developed all 6 pages from scratch — no templates used |
| 3. SEO Setup | Configured meta tags, sitemap.xml, robots.txt, and location-based keywords |
| 4. Deployment | Deployed live on Netlify with custom domain and HTTPS |
| 5. Documentation | Delivered a full project handover document to the client |

---

## Features

- Fully responsive — mobile, tablet, and desktop
- Custom design built from scratch, no templates used
- Smooth CSS transitions and JavaScript scroll animations
- SEO optimized — meta tags, sitemap.xml, robots.txt, location-based keywords
- Fast loading — no frameworks, pure HTML/CSS/JS
- HTTPS secured via Netlify SSL
- Auto-deploys on every GitHub push
